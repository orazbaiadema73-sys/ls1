# ☕ Cafe App

React Native және Expo арқылы жасалған кафе қосымшасы. Пайдаланушы тіркеледі немесе кіреді, мәзірден тағам таңдайды, себетке салады және тапсырыс береді.

> Бұл оқу жобасы. Backend жоқ: авторизация мен тапсырыс демо түрінде жұмыс істейді, деректер қосымшаның ішінде сақталады.

## Мүмкіндіктер

**Авторизация**
- Телефон нөмірі мен пароль арқылы кіру
- Тіркелу (аты, телефон, пароль, шарттармен келісу)
- Парольді қалпына келтіру: нөмір енгізу, 4 таңбалы код растау, жаңа пароль орнату
- Қала таңдау

**Кафе**
- Мәзір: Кофе, Шай, Десерт, Тағам санаттары
- Атауы бойынша іздеу
- Өнім беті: сипаттамасы, өлшемі (S / M / L, бағасы өзгереді), саны
- Себет: санын өзгерту, «Кафеде» немесе «Өзімен алып кету» таңдау, жалпы баға
- Астыңғы навигация (Мәзір, Себет, Профиль) және себеттегі зат санының белгісі
- Профиль экраны

## Технологиялар

- [React Native](https://reactnative.dev/)
- [Expo](https://expo.dev/) (Expo Go арқылы іске қосылады)
- TypeScript

Қосымша пакеттер қолданылмайды (тек `expo-status-bar`). Навигация `useState` арқылы жасалған.

## Іске қосу

Қажет: [Node.js](https://nodejs.org/) және телефонда Expo Go (немесе Android эмуляторы).

```bash
# 1. Репозиторийді жүктеп ал
git clone https://github.com/СЕНІҢ_ЛОГИНІҢ/cafe-app.git
cd cafe-app

# 2. Тәуелділіктерді орнат
npm install

# 3. Іске қос
npx expo start
```

Терминалда шыққан QR кодты Expo Go арқылы сканерле. Android эмуляторында ашу үшін `a` пернесін бас немесе `npm run android` жаз.

Windows-та сертификат қатесі (TLS) шықса, алдымен PowerShell-де мынаны жаз:

```powershell
$env:NODE_OPTIONS="--use-system-ca"
```

## Мәзірді өзгерту

Тағамдар, бағалар мен сипаттамалар `src/data/menu.ts` файлында тұр. Жаңа өнім қосу үшін `PRODUCTS` тізіміне объект қос:

```ts
{ id: '11', name: 'Мокко', category: 'Кофе', price: 1400, emoji: '🍫', bg: '#F1E4DA', hasSizes: true,
  description: 'Эспрессо, шоколад және сүт.' }
```
